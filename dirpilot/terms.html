1. Purpose of the Software

DirPilot is a local folder workflow tool for Windows. It helps you inspect a proposed transfer and copy eligible content from a Source folder into an existing Target folder that you select.

In the current release, a push overwrites files in Target that have the same relative path as eligible files in Source. Files that exist only in Target are kept. DirPilot does not provide automatic rollback, versioned backups, saved tasks, cloud synchronization, or a guarantee that Target will exactly mirror Source.
