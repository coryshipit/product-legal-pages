Privacy Policy

Last updated: July 20, 2026

Summary

MarkGlide is a privacy-first Markdown ↔ HTML converter. All conversions happen locally on your device. Your documents never leave your computer.

  • Local processing by default — no document content is uploaded to any server by MarkGlide
  • No telemetry, no analytics, no tracking
  • No account required
  • Works fully offline

Data We Collect

We do not collect, receive, transmit, store on our servers, or otherwise have access to your personal data or document content. Any processing of your files occurs locally on your device at your direction. MarkGlide does not include any analytics SDK, crash reporter, or advertising tracker.

Local Processing

When you open a Markdown or HTML file in MarkGlide, the file content is read into your device's memory and converted by the conversion engine running locally. The converted output is also kept in memory until you choose to save it. At no point is your file content sent over the network or transferred internationally.

Local Storage

MarkGlide does not persist your document content except when you explicitly use the "Download" feature to save the converted output to a location you choose. Specifically:

  • No recent file list — MarkGlide does not remember files you have opened;
  • No auto-save or session restore — closing the app discards all current content;
  • No application logs — MarkGlide does not write file names, file paths, or error details to any log file;
  • No localStorage, sessionStorage, or IndexedDB usage — your browser-style storage inside the app is empty;
  • No temporary files — converted output is held only in memory until you save it.

The application itself stores only its executable and WebView2 runtime caches (such as compiled shader caches) in the standard Windows app data directory. These caches are managed by Windows and WebView2, contain no document content, and are not under MarkGlide's direct control. Windows may also generate crash dumps through Windows Error Reporting if the application unexpectedly terminates; those dumps are handled under Microsoft's own privacy terms.

Data Retention

Because MarkGlide does not collect, store, or transmit any personal data or document content, there is no data retention period to specify. Any content you process in MarkGlide remains solely on your device under your control.

No Account, No Authentication

MarkGlide does not require you to create an account, sign in, or authenticate in any way. There is no user database because there are no users to track.

Offline Operation

MarkGlide works fully offline. The core conversion engine (markdown-it for MD→HTML, Turndown for HTML→MD) runs entirely on your device. An internet connection is only required for the initial download and installation from the Microsoft Store, and for application updates distributed through the Store.

The Preview feature renders converted HTML in a sandboxed iframe. If your HTML contains image URLs pointing to external servers (e.g., <img src="https://...">), the browser will attempt to load those images when you switch to Preview view. This is the same behavior as opening an HTML file in a web browser. MarkGlide does not send your document content to any server — only the browser requests the image URLs that already exist in your document. If you prefer to avoid any network requests, you can stay in Code view where no external resources are loaded.

We do not control or receive that data unless Microsoft separately provides developer-facing reports through Partner Center.
